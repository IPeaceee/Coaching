Tìm kiếm và thay thế

n / NKết quả tiếp theo cùng chiều / ngược chiều

:%s/cu/moi/gThay tất cả trong file

Ký tự đặc biệt cần “escape” bằng \

## Thay /home/cybersys bằng /root/abc
:%s//home/cybersys//root/abc/g          # SAI
:%s/\/home\/cybersys/\/root\/abc/g      # ĐÚNG
:%s#/home/cybersys#/root/abc#g          # ĐÚNG, dễ đọc hơn
## Thay C:\> bằng D:\>
:%s/C:\\>/D:\\>/g
MẹoĐổi dấu phân cách sang # hoặc | khi chuỗi có nhiều dấu /.

Ví dụ

sed — tìm & thay thế không cần mở file

$ echo a12 > a12
$ sed 's/a12/a13/g' a12        # chỉ in ra màn hình
a13
$ cat a12
a12
$ sed -i 's/a12/a13/g' a12     # sửa thẳng vào file
$ cat a12
a13
$ sed -i.bak 's/22/2222/' cfg  # sửa + giữ bản cfg.bak
$ sed -n '5,10p' /etc/passwd   # in dòng 5 → 10
$ sed '/^#/d' /etc/fstab       # bỏ dòng chú thích
s/cu/moi/Thay lần đầu mỗi dòng
s/cu/moi/gThay mọi lần xuất hiện
-iGhi thẳng vào file (in-place)
-i.bakGhi thẳng + tạo bản sao lưu
-n 'Np'Chỉ in dòng N
'Nd' · '/mẫu/d'Xóa dòng N · dòng khớp mẫu
Luôn thử trướcChạy không có -i để xem kết quả, đúng rồi mới thêm -i.

$ echo 'export EDITOR=vim' >> ~/.bashrc
$ source ~/.bashrc
$ crontab -e                 # mở bằng $EDITOR
$ sudo visudo                # cũng dùng $EDITOR
## Debian/Ubuntu còn có:
$ select-editor
$ sudo update-alternatives --config editor

Lab 2 · 30 phút

Sửa file cấu hình thật — an toàn

  1. Sao lưu: cp /etc/ssh/sshd_config ~/lab4/sshd_config (ta chỉ sửa bản sao)
  2. Mở bằng vim, tìm dòng chứa Port bằng /Port
  3. Bỏ dấu # ở đầu dòng #Port 22 và đổi thành Port 2222, lưu
  4. Dùng sed (không mở file) đổi #PermitRootLogin prohibit-password thành PermitRootLogin no
  5. Kiểm tra bằng grep -n -E '^(Port|PermitRootLogin)' ~/lab4/sshd_config
  6. So sánh với bản gốc: diff /etc/ssh/sshd_config ~/lab4/sshd_config
Lời giải bước 4–6 
$ sed -i 's/^#PermitRootLogin prohibit-password/PermitRootLogin no/' ~/lab4/sshd_config
$ grep -n -E '^(Port|PermitRootLogin)' ~/lab4/sshd_config
21:Port 2222
40:PermitRootLogin no
$ diff /etc/ssh/sshd_config ~/lab4/sshd_config
Số dòng có thể khác tùy phiên bản OpenSSH. Nhấn mạnh quy tắc: luôn cp file.bak trước khi sửa cấu hình thật.

Bài tập

Luyện tập

  1. Bạn lỡ sửa linh tinh một file cấu hình trong vim. Thoát thế nào để không lưu?
    Đáp ánEsc rồi :q!
  2. Nhảy tới dòng 120 và xóa 4 dòng từ đó.
    Đáp án120G rồi 4dd (hoặc :120,123d)
  3. Thay mọi “http://” bằng “https://” trong file đang mở.
    Đáp án:%s#http://#https://#g
  4. Không mở file, đổi mọi chữ “centos” thành “rocky” trong ghichu.txt và giữ bản sao lưu.
    Đáp ánsed -i.bak 's/centos/rocky/g' ghichu.txt
  5. In ra dòng 1 đến 3 của /etc/passwd bằng sed.
    Đáp ánsed -n '1,3p' /etc/passwd
  6. Trong vim, đang ở INSERT, bạn muốn copy dòng hiện tại. Cần bấm gì?
    Đáp ánEsc (về NORMAL) rồi yy.

Trắc nghiệm nhanh · 5 phút

Kiểm tra trước khi về

  1. Hai cách lưu và thoát vi?
    Đáp án:wq và ZZ (thêm :x).
  2. Tìm chữ User theo chiều ngược lên đầu file?
    Đáp án?User, rồi n để sang kết quả kế tiếp.
  3. Biến nào quy định trình soạn thảo cho crontab -e?
    Đáp ánEDITOR (hoặc VISUAL).
