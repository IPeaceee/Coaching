Mục tiêu buổi học

Sau buổi này bạn có thể…

Kho của Ubuntu

/etc/apt/sources.list.d/ubuntu.sources (24.04) — bản cũ: /etc/apt/sources.list
update ≠ upgradeapt update chỉ tải danh sách gói mới. apt upgrade mới thực sự nâng cấp. (Trên dnf, update = nâng cấp.)
Ghi chú gốcapt-get, apt-cache, aptitude vẫn dùng được; apt là lệnh gộp, thân thiện hơn.

$ ldd /usr/bin/ls

Lab A · 30 phút

Thao tác với rpm và dnf

  1. Đếm số gói đã cài. Liệt kê các gói có chữ “kernel”
  2. Lệnh /usr/bin/ssh thuộc gói nào? Gói đó có những file cấu hình nào?
  3. Cài tree, vim-enhanced, bash-completion, wget trong một lệnh
  4. Thử cài htop → lỗi → bật EPEL → cài lại thành công
  5. Gỡ tree, rồi dùng dnf history để hoàn tác thao tác gỡ
  6. Tải (không cài) gói nano về /root/pkgs, kiểm tra chữ ký rpm -K, xem nội dung rpm -qlp, rồi cài bằng rpm -ivh
  7. Sửa /etc/nanorc rồi chạy rpm -V nano – đọc ý nghĩa các ký hiệu

Lab B · 30 phút

Dựng web server đầu tiên

  1. Cài httpd, khởi động và bật tự chạy khi boot
  2. Kiểm tra httpd đang lắng nghe cổng 80
  3. Tạo trang /var/www/html/index.html có tên bạn
  4. Từ chính server: curl localhost
  5. Lấy IP server bằng ip -4 a. Mở trình duyệt trên máy thật → http://IP → không vào được?
  6. Mở firewall cho dịch vụ http, thử lại → thấy trang của bạn

Bài tập

Luyện tập

  1. File /etc/ssh/sshd_config thuộc gói nào?
    Đáp ánrpm -qf /etc/ssh/sshd_config → openssh-server
  2. Lệnh semanage không có. Tìm gói cần cài.
    Đáp ándnf provides '*/semanage' → policycoreutils-python-utils
  3. Khác nhau giữa rpm -ivh và rpm -Uvh?
    Đáp án-i chỉ cài mới (lỗi nếu đã có); -U cài mới hoặc nâng cấp nếu đã có bản cũ.
  4. Trên Ubuntu, gỡ apache2 và xóa luôn file cấu hình.
    Đáp ánsudo apt purge apache2 && sudo apt autoremove
  5. Vì sao rpm -ivh một gói tải về báo “Failed dependencies”, còn dnf install ./gói.rpm thì thành công?
    Đáp ándnf tự tìm và cài các gói phụ thuộc từ kho; rpm thì không.
