Mount bind — “gắn” một thư mục vào chỗ khác

# mkdir /source-folder /destination-folder
# echo bind > /source-folder/bind-mount.txt
# mount --bind /source-folder /destination-folder
# ls /destination-folder
bind-mount.txt
## Bản chỉ đọc cho người khác xem
# mount -o remount,bind,ro /destination-folder
# rm -f /destination-folder/bind-mount.txt
rm: cannot remove '...': Read-only file system
# echo moi > /source-folder/moi.txt     # nguồn vẫn ghi được
# ls /destination-folder
bind-mount.txt  moi.txt

Một nội dung, hai đường dẫn. Phía nguồn sửa được, phía đích chỉ đọc – dùng để “phát hành” dữ liệu an toàn.

/source-folder  /destination-folder  none  bind,ro  0 0
Ghi chú gốcDùng 2 dòng: bind rồi remount,bind,ro. Từ util-linux 2.27 (Rocky 8/9, Ubuntu 18.04+) chỉ cần 1 dòng bind,ro.
# umount /destination-folder ; mount -a
# findmnt /destination-folder

Ví dụ · LPI 102.1 (tính năng cơ bản của LVM)

LVM thực hành nhanh

# pvcreate /dev/sdc3
  Physical volume "/dev/sdc3" successfully created.
# vgcreate vgdata /dev/sdc3
# lvcreate -n lvweb -L 1G vgdata
# mkfs.xfs /dev/vgdata/lvweb
# mkdir /web ; mount /dev/vgdata/lvweb /web
# df -h /web
/dev/mapper/vgdata-lvweb 1014M  40M  975M  4% /web
## Hết chỗ? Mở rộng ngay khi đang chạy
# lvextend -r -L +1G /dev/vgdata/lvweb
# df -h /web
/dev/mapper/vgdata-lvweb  2.0G  47M  2.0G  3% /web
# pvs ; vgs ; lvs
/dev/sdc3 → PV (pvcreate)
PV → VG vgdata (vgcreate, thêm ổ: vgextend)
VG → LV lvweb (lvcreate, lvextend)
-r = resize filesystemlvextend -r nới LV và filesystem trong 1 lệnh (xfs lẫn ext4).

Lab A · 45 phút

Gắn ổ đĩa mới cố định

  1. Xác định ổ mới bằng lsblk (giả sử /dev/sdc, 10 GB)
  2. Tạo 3 phân vùng primary: sdc1 4 GB · sdc2 3 GB · sdc3 phần còn lại, loại LVM (t → 8e)
  3. Định dạng: sdc1 → ext4, sdc2 → xfs
  4. Tạo /data-hdd và /archive, mount sdc1 và sdc2 vào đó
  5. Thêm 2 dòng vào /etc/fstab bằng UUID; umount cả hai rồi mount -a để kiểm tra
  6. Reboot, kiểm tra bằng df -hT
  7. (Mở rộng) Dùng sdc3 làm LVM theo slide trước, mount /web cố định
Gợi ý fstab 
# blkid /dev/sdc1 /dev/sdc2
# echo "UUID=$(blkid -s UUID -o value /dev/sdc1)  /data-hdd  ext4  defaults  0 2" >> /etc/fstab
# echo "UUID=$(blkid -s UUID -o value /dev/sdc2)  /archive   xfs   defaults  0 2" >> /etc/fstab
# systemctl daemon-reload ; mount -a ; df -hT | grep -E 'data-hdd|archive'

Lab B · 30 phút

ISO, bind read-only và quota

  1. Mount /dev/sr0 vào /mnt/cdrom, liệt kê nội dung, umount

Lab C · 35 phút · không cần thêm ổ thật

Ổ đĩa ảo: GPT, nhãn, fsck và “hết inode”

  1. Dùng file /root/disk.img 1 GB tạo ở B6 (chưa có thì tạo bằng dd)
  2. losetup -fP --show /root/disk.img → nhận thiết bị /dev/loop0
  3. gdisk /dev/loop0: bảng GPT, phân vùng 1 = 300 MB, phân vùng 2 = phần còn lại
  4. mkfs.ext4 -N 2000 -L THU /dev/loop0p1 (chỉ 2000 inode) · mkfs.xfs -L LUU /dev/loop0p2
  5. Mount bằng nhãn: mount LABEL=THU /mnt/thu. Tạo 3000 file rỗng – lỗi gì? So sánh df -h và df -i
  6. umount, chạy e2fsck -f, tune2fs -l, xfs_repair -n
  7. Dọn dẹp: umount, losetup -d /dev/loop0
Gợi ý lời giải 
# losetup -fP --show /root/disk.img
/dev/loop0

Bài tập

Luyện tập

  1. Vì sao nên dùng UUID thay vì /dev/sdb1 trong fstab?
    Đáp ánTên thiết bị có thể đổi khi thêm/bớt ổ hoặc đổi thứ tự cổng; UUID gắn với filesystem, không đổi.
  2. Lệnh nào cho biết /home đang nằm trên thiết bị nào, loại filesystem gì?
    Đáp ánfindmnt /home hoặc df -hT /home
  3. Viết dòng fstab mount /dev/sdd1 (xfs) vào /logs, không cho chạy file thực thi.
    Đáp ánUUID=… /logs xfs defaults,noexec 0 2
  4. umount báo “target is busy”. Bạn làm gì?
    Đáp ánRa khỏi thư mục (cd), đóng chương trình đang dùng; tìm bằng lsof +D / fuser -vm.
  5. Mount file ubuntu.iso vào /mnt/u.
    Đáp ánmkdir -p /mnt/u; mount -o loop ubuntu.iso /mnt/u
  6. LV /dev/vgdata/lvweb sắp đầy, VG còn 2 GB trống. Tăng thêm 1 GB?
    Đáp ánlvextend -r -L +1G /dev/vgdata/lvweb

Kiểm tra trước khi về

  1. df -h còn trống nhưng không tạo được file. Kiểm tra gì?
    Đáp ándf -i – có thể đã hết inode.
  2. Viết dòng fstab mount theo nhãn DATA vào /data (ext4)?
    Đáp ánLABEL=DATA /data ext4 defaults 0 2
  3. Có được chạy fsck trên phân vùng đang mount đọc-ghi không?
    Đáp ánKhông – umount trước (hoặc kiểm tra lúc boot).
