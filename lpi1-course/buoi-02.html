Làm quen dòng lệnh & di chuyển trong hệ thống

Shell, dấu nhắc lệnh, cấu trúc câu lệnh, đường dẫn, cd · ls · man và xem thông tin phần cứng.

Mục tiêu buổi học

Sau buổi này bạn có thể…

  • Đọc được dấu nhắc lệnh và biết mình đang là ai, đang ở đâu
  • Viết đúng cấu trúc lệnh [tùy chọn] [đối số]; dùng đúng dấu nháy, biến và export
  • Phân biệt đường dẫn tuyệt đối và tương đối; di chuyển bằng cd
  • Đọc kết quả ls -l và tự tra cứu bằng man, --help
  • Tìm vị trí lệnh (which, whereis, locate), xem phần cứng qua /proc, /sys, lspci, lsmod

Lý thuyết

Terminal, shell và cách mở dòng lệnh

Terminal: cửa sổ để gõ chữ. Shell: chương trình đọc lệnh bạn gõ và chạy nó. Shell mặc định trên Linux là bash.

  • Máy server (không đồ họa): đăng nhập là có shell ngay
  • Chuyển console ảo: Ctrl+Alt+F1…F6
  • Desktop: Ctrl+Alt+T (Ubuntu) hoặc Alt+F2 → gnome-terminal
  • Từ xa: SSH (buổi 13)
$ echo $SHELL
/bin/bash
$ cat /etc/shells
/bin/sh
/bin/bash
/usr/bin/sh
/usr/bin/bash
Giao diện đồ họa (biết tên)GNOME, KDE Plasma, XFCE, Cinnamon. Server thường không cài để tiết kiệm tài nguyên.

Cách viếtShell xử lý bên trong thế nào

Lệnh nội bộ và lệnh ngoàicd, echo, export nằm sẵn trong bash. ls, cp là file trong /usr/bin, tìm theo PATH (B3). Lệnh ngoài PATH phải gõ đường dẫn: ./script.sh.

Lab · 50 phút

Khám phá hệ thống của bạn

  1. Đăng nhập bằng user thường. Chạy whoami, id, pwd – ghi lại kết quả
  2. Đi tới /var/log bằng đường dẫn tuyệt đối, sau đó tới /etc/ssh bằng đường dẫn tương đối
  3. Quay về home bằng 2 cách khác nhau. Dùng cd - để quay lại /etc/ssh
  4. Liệt kê tất cả file (cả file ẩn) trong home, dạng dài, kích thước dễ đọc
  5. Xem thông tin của chính thư mục /etc (không liệt kê nội dung bên trong)
  6. Tìm file thực thi của passwd và ssh; mở man passwd, tìm từ “lock”
  7. Lập hồ sơ server1: số core, RAM, swap, kernel, dung lượng trống / và /home, driver card mạng (lspci -k)
  8. Chuyển sang root bằng su -, chạy lại id, rồi exit để quay về

Bài tập

Thử thách

  1. Đang ở /var/log. Viết lệnh cd bằng đường dẫn tương đối để tới /etc/ssh.
    Đáp áncd ../../etc/ssh
  2. Liệt kê file trong /etc, file sửa gần nhất nằm trên cùng.
    Đáp ánls -lt /etc
  3. Vì sao ls /etc và ls -ld /etc cho kết quả khác nhau?
    Đáp ánls /etc liệt kê nội dung bên trong; -d hiển thị thông tin của chính thư mục /etc.
  4. Lệnh ll có phải là một chương trình riêng không? Kiểm tra thế nào?
    Đáp ánKhông, là alias của ls -l. Kiểm tra bằng type ll hoặc alias.
  5. Máy có bao nhiêu MB RAM còn khả dụng?
    Đáp ánfree -m → cột available.
  6. Tạo file tên bao cao.txt (có dấu cách) rồi liệt kê nó.
    Đáp ántouch "bao cao.txt"; ls -l "bao cao.txt" (hoặc bao\ cao.txt)
