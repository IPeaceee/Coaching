Lý thuyết · LPI 102.2 — vẫn có trong đề

GRUB Legacy — file cấu hình viết tay

# mục mặc định, đếm từ 0; mục 0 lỗi thì thử mục 1
default=0
fallback=1
timeout=5
# (hd0,0) = ổ thứ nhất, phân vùng thứ nhất = /dev/sda1
title CentOS (2.6.32-504.el6.x86_64)
        root (hd0,0)
        kernel /vmlinuz-2.6.32-504.el6.x86_64 ro root=/dev/mapper/vg-lv_root rhgb quiet
        initrd /initramfs-2.6.32-504.el6.x86_64.img
# grub-install /dev/sda       # cài GRUB vào MBR của ổ sda
## trong grub shell (Legacy):
grub> root (hd0,0)
grub> setup (hd0)
Ghi chú gốcBài 12 của ghi chú sửa /boot/grub/grub.conf thêm khối title/root/kernel/initrd – chính là GRUB Legacy trên CentOS 5/6.

Lý thuyết · LPI 102.2

GRUB Legacy so với GRUB 2

GRUB LegacyGRUB 2
File cấu hìnhSửa tay menu.lst / grub.confSửa /etc/default/grub, /etc/grub.d/40_custom → sinh grub.cfg
Sinh cấu hình—grub-mkconfig -o /boot/grub/grub.cfg (= update-grub); Rocky: grub2-mkconfig -o /boot/grub2/grub.cfg
Đánh số /dev/sda1(hd0,0) – phân vùng đếm từ 0(hd0,msdos1) / (hd0,gpt1) – đếm từ 1
Mục mặc địnhdefault=0, dự phòng fallback=1GRUB_DEFAULT=0 hoặc saved; khởi động 1 lần: grub-reboot
Khi boote sửa, c dòng lệnh, b boote sửa, c dòng lệnh, Ctrl+X boot
Mẹo nhớ cho đề thiLegacy đếm phân vùng từ 0, GRUB 2 đếm từ 1; cả hai đếm ổ từ 0.
Đừng sửa grub.cfg bằng tayLần chạy grub-mkconfig sau sẽ ghi đè. Mục menu riêng đặt trong /etc/grub.d/40_custom.
Liên kếtB1: /boot và ESP · B11: /dev/sda1, UUID – GRUB dùng để tìm kernel.

Ví dụ · LPI 101.2

Tham số kernel và nhật ký khởi động

$ cat /proc/cmdline

Ví dụ

Khôi phục mật khẩu root — Rocky Linux 9

  1. Khởi động lại, tại menu GRUB bấm e trên dòng kernel đầu tiên
  2. Tìm dòng bắt đầu bằng linux, thêm vào cuối dòng: rd.break
  3. Bấm Ctrl+X để boot → vào shell switch_root:/#
  4. Gõ các lệnh bên phải
  5. exit hai lần → máy tự khởi động tiếp (relabel SELinux mất 1–2 phút)
switch_root:/# mount -o remount,rw /sysroot
switch_root:/# chroot /sysroot
sh-5.1# passwd root
New password:
Retype new password:
sh-5.1# touch /.autorelabel
sh-5.1# exit
switch_root:/# exit
Đừng quên /.autorelabelThiếu bước này, SELinux thấy /etc/shadow sai nhãn → không ai đăng nhập được.
Ghi chú gốc (CentOS 5/6)Thêm single (hoặc 1, -s) cuối dòng kernel → vào thẳng root shell → passwd.

Ví dụ

Khôi phục mật khẩu — Ubuntu

Cách 1: sửa tham số kernel

  1. Giữ Shift (BIOS) hoặc bấm Esc (UEFI) khi boot để hiện GRUB
  2. e → dòng linux …: thay ro quiet splash bằng rw init=/bin/bash
  3. Ctrl+X → có root shell
root@(none):/# passwd nhanle
root@(none):/# sync
root@(none):/# exec /sbin/init

Cách 2: Recovery mode

  1. GRUB → Advanced options for Ubuntu → dòng (recovery mode)
  2. Chọn root — Drop to root shell prompt
# mount -o remount,rw /
# passwd nhanle
# reboot
Bài học bảo mậtAi chạm được vào máy (hoặc console VM) là lấy được root. Bảo vệ: mật khẩu GRUB, mã hóa ổ đĩa, khóa BIOS, khóa phòng máy.

Ví dụ

Mật khẩu GRUB và cứu hộ bằng đĩa cài

Đặt mật khẩu cho GRUB

# grub2-setpassword          # Rocky / RHEL
Enter password:
Confirm password:
# cat /boot/grub2/user.cfg
GRUB2_PASSWORD=grub.pbkdf2.sha512.10000.8C2E...

Từ giờ bấm e trong GRUB sẽ hỏi user root + mật khẩu này.

Ghi chú gốcgrub-md5-crypt + dòng password --md5 … trong grub.conf (GRUB cũ).

Khi quên cả mật khẩu GRUB: dùng đĩa cài

  1. Boot từ ISO Rocky → Troubleshooting → Rescue a Rocky Linux system
  2. Chọn 1) Continue → hệ thống được mount ở /mnt/sysroot
sh-5.1# chroot /mnt/sysroot
sh-5.1# passwd root
sh-5.1# touch /.autorelabel
sh-5.1# exit ; reboot

CentOS 6 (ghi chú gốc): chọn linux rescue → chroot /mnt/sysimage.

Mở rộng

Sửa GRUB sau khi cài lại Windows (dual-boot)

Cài lại Windows ghi đè bootloader → không vào được Linux. Cứu bằng USB Linux Live:

## giả sử / là sda3, /boot là sda1 (xem bằng lsblk)
# mount /dev/sda3 /mnt
# mount /dev/sda1 /mnt/boot
# for d in dev proc sys; do mount --bind /$d /mnt/$d; done
# chroot /mnt
# grub2-install /dev/sda                 # Ubuntu: grub-install
# grub2-mkconfig -o /boot/grub2/grub.cfg # Ubuntu: update-grub
# exit ; reboot
Máy UEFIMount thêm phân vùng EFI vào /mnt/boot/efi; thường chỉ cần chọn lại thứ tự boot trong UEFI hoặc dùng efibootmgr.
Ghi chú gốcChiều ngược lại – xóa Linux làm Windows không boot – sửa bằng đĩa Windows: bootrec /fixmbr, bootrec /fixboot (XP: fixmbr; Win 7: bootsect /nt60 C:).

Lab · 30 phút

Lấy lại mật khẩu root

  1. Chụp snapshot. Đặt mật khẩu root thành một chuỗi ngẫu nhiên bạn không ghi lại: openssl rand -base64 12 | passwd --stdin root
  2. Reboot, khôi phục mật khẩu root bằng rd.break
  3. Đăng nhập root bằng mật khẩu mới. Kiểm tra SELinux vẫn Enforcing (getenforce)
  4. Đặt mật khẩu GRUB bằng grub2-setpassword, reboot, thử bấm e
  5. (Nếu có VM Ubuntu) khôi phục mật khẩu user đầu tiên bằng init=/bin/bash
  6. Quay lại snapshot 14-before-recovery trước khi thi
Nếu học viên quên touch /.autorelabel: boot lại với rd.break, chroot, touch /.autorelabel. Hoặc thêm enforcing=0 vào dòng kernel để đăng nhập rồi chạy restorecon -v /etc/shadow.

Thi thử · 90 phút

Đề thi kết thúc môn LPI-I

  1. IP tĩnh cho card mạng: 192.168.229.29/255.255.255.0, gateway 192.168.229.2, DNS 8.8.8.8. Kiểm tra kết nối Internet.
  2. Trên card mạng đầu tiên gán thêm IP phụ: 192.168.255.129/255.255.255.0.
  3. Dùng wget tải mã nguồn WordPress (https://wordpress.org/latest.tar.gz). Tạo user hocvien, test. Trong home của hocvien tạo thư mục temp, public_html; giải nén WordPress vào public_html.
  4. Phân quyền: mọi file/thư mục trong /home/hocvien có chủ là hocvien, nhóm root, quyền 750. Chỉ user test (ngoài chủ và nhóm) có quyền đọc & thực thi.
  5. Tạo /opt/public_html. Mount bind /home/hocvien/public_html → /opt/public_html, phía /opt chỉ đọc, vẫn tồn tại sau khi khởi động lại.

Điều kiện

Máy ảo Rocky Linux 9 (đề gốc: CentOS 6) không giao diện đồ họa. VMnet8 đặt mạng 192.168.229.0/24.

Thi thử trắc nghiệm · làm ở nhà

Đề thi LPIC-1 thật trông như thế nào?

  • Mỗi bài (101, 102): 60 câu trong 90 phút, trên máy tính
  • Phần lớn là trắc nghiệm một đáp án; có câu chọn nhiều và câu điền lệnh/tên file

  • Hỏi chính xác tùy chọn lệnh và cả công cụ cũ: SysVinit, GRUB Legacy, yum, zypper
