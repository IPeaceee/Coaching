Mục tiêu buổi học

Sau buổi này bạn có thể…

  • Tạo file, thư mục (kể cả nhiều cấp) chỉ bằng 1 lệnh
  • Sao chép, đổi tên, di chuyển, xóa an toàn
  • Dùng * ? [ ] { } để thao tác hàng loạt
  • Tìm file theo tên, loại, chủ sở hữu, kích thước, thời gian
  • Chọn đúng giữa copy, hard link và symbolic link
  • Biết mỗi loại file nằm ở đâu theo FHS; nhận diện file bằng file
  • Tạo alias, dùng lại lệnh cũ với history
  • Hiểu biến môi trường và PATH, lưu cấu hình vào ~/.bashrc
Ôn bài cũĐường dẫn tuyệt đối khác tương đối thế nào? cd - làm gì? Xem file ẩn bằng lệnh nào?

Ví dụ

Tạo file: touch và xem thuộc tính bằng stat

$ mkdir ~/test_touch && cd ~/test_touch
$ touch 123456.txt
$ ls -l
-rw-r--r--. 1 antm antm 0 Oct 19 16:07 123456.txt
$ touch 123456.txt          # chạm lại: đổi giờ
$ touch -t 202503141500 123456.txt
$ ls -l 123456.txt
-rw-r--r--. 1 antm antm 0 Mar 14  2025 123456.txt
$ echo "xin chao" > hello.txt   # tạo file có nội dung
  • File chưa có → touch tạo file rỗng
  • File đã có → cập nhật thời gian (timestamp)
  • -t YYYYMMDDhhmm: đặt thời gian tùy ý
$ stat 123456.txt
  File: 123456.txt
  Size: 0     Blocks: 0   regular empty file
Access: (0644/-rw-r--r--)  Uid: (1000/antm)
Access: 2025-03-14 15:00:00 +0700
Modify: 2025-03-14 15:00:00 +0700
Change: 2026-10-19 16:18:23 +0700

Access = lần đọc · Modify = lần sửa nội dung · Change = lần đổi thuộc tính (quyền, tên…)

Ví dụ

Sao chép cp và di chuyển / đổi tên mv

$ cp hello.txt hello.bak
$ cp -v hello.txt /tmp/
'hello.txt' -> '/tmp/hello.txt'
$ cp -r Test1000 Test1000-copy
$ cp -a /etc/ssh ~/ssh-backup   # giữ quyền, giờ
$ cp -i hello.txt hello.bak
cp: overwrite 'hello.bak'? n
-rChép thư mục (đệ quy)
-iHỏi trước khi ghi đè
-vHiện chi tiết
-aLưu trữ: đệ quy + giữ quyền, chủ, thời gian
$ mv hello.bak hello.old        # đổi tên
$ mv hello.old Test/            # di chuyển
$ mv -v t1 t2 t3 Test/          # nhiều thứ vào 1 thư mục

renamed 't2' -> 'Test/t2'

Một lệnh, hai việcLinux không có lệnh “rename” riêng – mv vừa đổi tên vừa di chuyển.

Ví dụ

Xóa với rm — không có thùng rác!

$ rm hello.txt
$ rm -i 123456.txt
rm: remove regular empty file '123456.txt'? y
$ rm Test
rm: cannot remove 'Test': Is a directory
$ rm -r Test
$ rm -rf Test1000-copy     # không hỏi gì cả
$ rmdir t1                 # chỉ xóa thư mục rỗng
Nguy hiểmrm -rf với quyền root xóa vĩnh viễn, không hỏi. Một dấu cách sai: rm -rf / tmp/abc = xóa toàn bộ hệ thống.
Thói quen an toàn
  • Chạy ls với đúng mẫu trước, rồi mới đổi ls → rm
  • Dùng rm -i khi chưa chắc
  • Không gõ rm -rf khi đang là root nếu không thật cần
Ghi chúTrên Rocky, root có sẵn alias rm='rm -i', cp='cp -i', mv='mv -i'.

Ký tự đại diện (wildcard / globbing)

MẫuKhớp vớiVí dụ khớp
*0 hoặc nhiều ký tự bất kỳ*.txt → a.txt, bao-cao.txt
?Đúng 1 ký tựfile?.log → file1.log
[abc]1 ký tự trong tập[ab]*.txt → a1.txt, b.txt
[0-9]1 ký tự trong khoảnglog[0-9] → log7
[!0-9]KHÔNG thuộc tập[!a]* → b.txt
{a,b}Sinh chuỗi (không cần file tồn tại){1..5} → 1 2 3 4 5
$ touch file{1..5}.log bao-cao.txt a.txt
$ ls *.log
file1.log file2.log file3.log file4.log file5.log
$ ls file[2-4].log
file2.log file3.log file4.log
$ ls ?.txt
a.txt
$ rm -v file[13].log
removed 'file1.log'
removed 'file3.log'

Tìm kiếm với find

Cú pháp: find [nơi tìm] [điều kiện] [hành động]

# find /usr/sbin -name "use?add"
/usr/sbin/useradd
# find /usr/bin -name "pass*"
/usr/bin/passwd
# find /home -user antm -name ".bash*"
/home/antm/.bash_logout
/home/antm/.bash_profile
/home/antm/.bashrc
$ find . -type d                 # chỉ thư mục
$ find . -type f -name ".*"      # file ẩn
# find /var/log -size +1M
# find /etc -mtime -1            # sửa trong 24h qua
$ find ~ -name "*.log" -delete
-name "mẫu"Theo tên (phân biệt hoa thường)
-inameTheo tên, không phân biệt hoa thường
-type f / d / lFile / thư mục / link
-user · -groupTheo chủ sở hữu
-size +10MLớn hơn 10 MB (- = nhỏ hơn)
-mtime -7Sửa trong 7 ngày qua
-exec cmd {} \;Chạy lệnh cho từng kết quả
Luôn đặt mẫu trong ngoặc kép-name "*.txt" – nếu không, shell sẽ tự mở rộng * trước khi find nhận được.

$ echo "noi dung" > goc.txt
$ ln -s goc.txt loi-tat.txt        # symbolic link
$ ln goc.txt cung.txt              # hard link
$ ls -li

cat: loi-tat.txt: No such file or directory

Symbolic link (ln -s)

Giống “shortcut” trên Windows. Trỏ tới tên file; file gốc mất → link “gãy”. Trỏ được tới thư mục, khác phân vùng.

Hard link (ln)

Một tên nữa cho cùng dữ liệu (cùng số inode). Xóa 1 tên, dữ liệu vẫn còn. Không áp dụng cho thư mục.

Ví dụ thực tế: ls -l /etc/localtime là symlink tới múi giờ.

FHS: mỗi loại file có “nhà” riêng

Thư mụcChứa gì
/usr/bin · /usr/sbinLệnh người dùng · lệnh quản trị (do gói cài)
/usr/lib, /usr/lib64Thư viện chia sẻ (B7)
/usr/localPhần mềm/script tự cài cho máy này
/optPhần mềm bên thứ ba đóng gói trọn bộ
/var/log · /var/lib · /var/spoolLog · dữ liệu trạng thái (CSDL rpm) · hàng đợi (cron, mail)
/tmp · /var/tmpTạm, có thể bị xóa khi reboot · tạm, giữ qua reboot
/srvDữ liệu máy chủ phục vụ ra ngoài (web, FTP)
/runDữ liệu lúc chạy (PID, socket), nằm trong RAM
/media · /mntUSB tự mount · mount tạm bằng tay

Đừng đoán loại file qua đuôi: dùng file

$ file /etc/passwd /usr/bin/ls /dev/sda
/etc/passwd: ASCII text
/usr/bin/ls: ELF 64-bit LSB pie executable, x86-64
/dev/sda:    block special (8/0)
Liên kếtB7 cài GNU hello vào /opt/hello, B9 đặt web vào /srv/webapp, B13 đặt script vào /root hoặc /usr/local/sbin.

Ví dụ

Alias và history — gõ ít, làm nhiều

$ alias
alias ll='ls -l --color=auto'
alias l.='ls -d .* --color=auto'
$ alias copy='cp -v'
$ alias ports='ss -tulnp'
$ unalias copy

Alias gõ ở dòng lệnh mất khi đăng xuất. Muốn giữ lâu dài → thêm vào ~/.bashrc:

$ echo "alias ll='ls -lh --color=auto'" >> ~/.bashrc
$ source ~/.bashrc
$ history | tail -3
  101  cd /etc
  102  ls -l
  103  history | tail -3
$ !102          # chạy lại lệnh số 102
$ !!            # chạy lại lệnh vừa xong
$ sudo !!       # lệnh vừa xong + sudo
$ !find         # lệnh gần nhất bắt đầu bằng find
$ history -c    # xóa lịch sử phiên hiện tại
$ echo $HISTFILE $HISTSIZE
/home/antm/.bash_history 1000
Phím vàngCtrl+R rồi gõ vài chữ → tìm ngược trong lịch sử.

Lý thuyết

Biến môi trường và PATH

$ echo $HOME $USER
/home/antm antm
$ echo $PATH
/home/antm/.local/bin:/home/antm/bin:/usr/local/bin:/usr/bin
$ env | head -3          # mọi biến môi trường
$ TEN="Linux"; echo "Xin chao $TEN"
Xin chao Linux
$ export PATH=$PATH:/opt/tools/bin

PATH = danh sách thư mục shell tìm lệnh, theo thứ tự, ngăn cách bằng :. Lệnh nằm ngoài PATH phải gõ đường dẫn đầy đủ (vd /opt/tools/bin/abc hoặc ./script.sh).

FileKhi nào chạy
~/.bash_profileĐăng nhập (login shell)
~/.bashrcMỗi lần mở shell mới
/etc/profile, /etc/bashrcCho mọi user
Ghi chú gốcCentOS 6: user thường gõ ifconfig bị “command not found” vì /sbin không nằm trong PATH.
Lưu cố địnhThêm export PATH=$PATH:/opt/tools/bin vào ~/.bashrc.

Lab · 60 phút

Dựng cây thư mục công ty

  1. Trong home, tạo bằng một lệnh: congty/{ketoan,nhansu,kythuat}/{2025,2026}
  2. Tạo các file bc-thang{1..12}.txt trong congty/ketoan/2026
  3. Chép toàn bộ thư mục ketoan thành ketoan-backup
  4. Đổi tên kythuat thành it; chuyển bc-thang1..3 sang 2025
  5. Xóa các file tháng 10–12 trong backup chỉ bằng 1 lệnh có wildcard
  6. Dùng find: đếm số file .txt trong congty; liệt kê các thư mục rỗng (-empty)
  7. Tạo symlink ~/ketoan-nay trỏ tới congty/ketoan/2026, cd qua link
  8. Tạo alias cty='cd ~/congty && tree', lưu vào ~/.bashrc, mở shell mới thử lại
congty/
├── it/
│   ├── 2025/
│   └── 2026/
├── ketoan/
│   ├── 2025/  bc-thang1..3
│   └── 2026/  bc-thang4..12
├── ketoan-backup/
│   └── 2026/  bc-thang1..9
└── nhansu/

Lab · Gợi ý lời giải

Lời giải tham khảo

Hiện lời giải 
$ cd ~ && mkdir -p congty/{ketoan,nhansu,kythuat}/{2025,2026}
$ touch congty/ketoan/2026/bc-thang{1..12}.txt
$ cp -r congty/ketoan congty/ketoan-backup
$ mv congty/kythuat congty/it
$ mv congty/ketoan/2026/bc-thang[1-3].txt congty/ketoan/2025/
$ rm -v congty/ketoan-backup/2026/bc-thang1[0-2].txt
$ find congty -type f -name "*.txt" | wc -l
21
$ find congty -type d -empty
$ ln -s ~/congty/ketoan/2026 ~/ketoan-nay && cd ~/ketoan-nay && pwd -P
$ echo "alias cty='cd ~/congty && tree'" >> ~/.bashrc && source ~/.bashrc
Bẫybc-thang[1-3].txt khớp 1, 2, 3 nhưng không khớp 10–12 vì sau chữ số là .txt. Còn bc-thang1* lại khớp 1, 10, 11, 12!
Số file: 12 file trong ketoan (3 ở 2025 + 9 ở 2026) + 9 file trong backup = 21. Cho học viên tự giải thích vì sao ra 21.

Bài tập

Luyện tập

  1. Tạo cấu trúc du-an/{web,app}/{src,docs} bằng 1 lệnh.
    Đáp ánmkdir -p du-an/{web,app}/{src,docs}
  2. Tìm trong /etc các file có đuôi .conf, không phân biệt hoa thường.
    Đáp ánfind /etc -type f -iname "*.conf"
  3. Tìm các file > 50 MB trên toàn hệ thống, bỏ qua thông báo lỗi.

  4. Đổi timestamp file a.txt thành 8h00 ngày 01/01/2025.
    Đáp ántouch -t 202501010800 a.txt
  5. Tại sao cp thu_muc /tmp báo lỗi “omitting directory”?
    Đáp ánThiếu -r – cp mặc định chỉ chép file.
  6. Thêm ~/scripts vào PATH vĩnh viễn cho user hiện tại.
    Đáp ánecho 'export PATH=$PATH:$HOME/scripts' >> ~/.bashrc; source ~/.bashrc (dùng nháy đơn để $PATH không bị mở rộng ngay)
