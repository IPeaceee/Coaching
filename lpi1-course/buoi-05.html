Ví dụ

xargs và một chút awk

xargs: biến đầu ra thành đối số

$ find ~/lab -name "*.tmp" | xargs rm -v
$ find ~/lab -type f | xargs ls -lh
## tương đương, an toàn với tên có dấu cách:
$ find ~/lab -name "*.tmp" -exec rm -v {} \;

Nhiều lệnh (rm, chmod, ls) không đọc stdin – chúng cần đối số. xargs làm cầu nối.

awk: xử lý theo cột

$ awk -F: '{print $1, $3}' /etc/passwd | head -2
root 0
bin 1
$ awk -F: '$3 >= 1000 {print $1}' /etc/passwd
antm
$ df -h | awk '{print $5, $6}'

-F: = phân cách cột; $1 = cột 1; điều kiện đặt trước { }.

Ví dụ · LPI 103.2

Checksum: file có còn nguyên vẹn?

$ sha256sum 1trieu.txt
f0f3…9a2c  1trieu.txt
$ sha256sum 1trieu.txt > 1trieu.sha256
$ sha256sum -c 1trieu.sha256
1trieu.txt: OK
$ echo 1 >> 1trieu.txt
$ sha256sum -c 1trieu.sha256
1trieu.txt: FAILED
sha256sum: WARNING: 1 computed checksum did NOT match
$ md5sum 1trieu.txt ; sha512sum 1trieu.txt
  • Chỉ cần đổi 1 byte, chuỗi checksum thay đổi hoàn toàn
  • Dùng để kiểm tra file ISO tải về, bản sao lưu, file chép qua mạng
  • -c đọc file danh sách và báo OK/FAILED từng file
md5 đã cũmd5 vẫn dùng để phát hiện lỗi chép file, nhưng không dùng cho bảo mật. Ưu tiên sha256/sha512.
Liên kếtB1: kiểm tra ISO Rocky trước khi cài · B13: kiểm tra bản sao lưu sau khi rsync.

Lý thuyết · LPI 103.7

Regex mở rộng: BRE và ERE

Ý nghĩaBRE (grep, sed)ERE (grep -E, sed -E)
0 hoặc nhiều lần**
1 hoặc nhiều lần\++
0 hoặc 1 lần\??
Từ n đến m lần\{n,m\}{n,m}
Nhóm · hoặc\( \) · \|( ) · |
[[:digit:]] [[:alpha:]]Chữ số · chữ cái
[[:space:]] [[:upper:]]Khoảng trắng · chữ hoa
grep -F (= fgrep)Chuỗi cố định, không regex
$ grep -E '^[0-9]{3}' test_grep.txt
123linux Cybersys123
123LINUX Cybersys
$ grep -iE 'linux[0-9]+' test_grep.txt
linux456 aaa
LINUX456 123
$ grep -E '^(root|antm):' /etc/passwd
$ grep -c '[[:digit:]]' test_grep.txt
7
$ grep -F 'a.a' test_grep.txt     # "." là dấu chấm thật
$ grep -Ev '^[[:space:]]*(#|$)' /etc/ssh/sshd_config
$ man 7 regex
Cách nhớERE = viết “sạch”, ít dấu \. Khi mẫu có + ? { } | ( ), dùng grep -E.

Ví dụ · LPI 103.7 · 103.4

sed nâng cao và here-document

$ sed -n '/^root/p' /etc/passwd          # in dòng khớp
$ sed '1,5d' file                        # xóa dòng 1–5
$ sed '/^#/d; /^$/d' sshd_config         # 2 lệnh liền nhau
$ sed -E 's/^([^:]+):.*/\1/' /etc/passwd # nhóm \1 = cột 1
$ sed -E 's/([0-9]{3})-([0-9]{4})/\2-\1/' <<< "090-1234"
1234-090
$ sed '3i\Dong chen o dong 3' file
$ sed '$a\Dong cuoi' file

Địa chỉ: số dòng, khoảng 1,5, mẫu /regex/, $ = dòng cuối.

Here-document: đưa nhiều dòng làm stdin

# cat > /etc/motd << EOF

EOF
$ wc -w <<< "mot hai ba"      # here-string
3

Bài tập

Luyện tập

  1. Lưu danh sách file trong /etc vào etc.txt, sau đó nối thêm danh sách /var vào cuối.
    Đáp ánls /etc > etc.txt; ls /var >> etc.txt
  2. Chạy find / -name passwd nhưng ẩn mọi thông báo lỗi.
    Đáp ánfind / -name passwd 2>/dev/null
  3. Đếm số dòng trong /etc/services có chứa “tcp”.
    Đáp ángrep -c tcp /etc/services
  4. Hiện 5 file lớn nhất trong /var/log.
    Đáp ánls -lS /var/log | head -6 hoặc du -a /var/log | sort -rn | head -5
  5. In các dòng của /etc/group có nhóm bắt đầu bằng chữ “w”.
    Đáp ángrep '^w' /etc/group
  6. Tìm mọi file .txt trong ~/lab5 rồi đếm tổng số dòng của chúng.
    Đáp ánfind ~/lab5 -name "*.txt" | xargs wc -l

Trắc nghiệm nhanh · 5 phút

Kiểm tra trước khi về

  1. Ghi cả stdout và stderr của cmd vào out.txt?
    Đáp áncmd > out.txt 2>&1 (hoặc cmd &> out.txt). Đảo thứ tự 2>&1 > out.txt thì lỗi vẫn ra màn hình.
  2. Với grep -E, mẫu ab+c khớp ac không?
    Đáp ánKhông – + cần ít nhất một chữ b.
  3. Kiểm tra các file theo danh sách checksum trong SHA256SUMS?
    Đáp ánsha256sum -c SHA256SUMS
