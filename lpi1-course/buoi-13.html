SSH — điều khiển máy từ xa qua kênh mã hóa

  • Server: gói openssh-server, dịch vụ sshd, cổng TCP 22
  • Client: lệnh ssh có sẵn trên Linux, macOS, Windows 10/11 (PowerShell)
  • Client đồ họa: PuTTY, MobaXterm, Bitvise, SecureCRT; chép file: WinSCP

rsync — đồng bộ thông minh, chỉ chép phần thay đổi

# dnf install -y rsync              # cài trên CẢ HAI máy
# mkdir /backup
# rsync -av /home /backup           # → /backup/home/...

test.txt                            ← chỉ chép file mới

-aarchive = đệ quy + giữ link, quyền, thời gian, chủ, nhóm (-rlptgoD)
-vHiện chi tiết
-uBỏ qua file ở đích mới hơn
-zNén khi truyền qua mạng

Dấu / cuối nguồn rất quan trọng/home = chép cả thư mục home · /home/ = chép nội dung bên trong. Với --delete, chọn sai có thể xóa nhầm. Luôn chạy -n trước.

Lý thuyết

Script bash: tự động hóa chuỗi lệnh

#!/bin/bash
# Sao luu /etc moi ngay, giu lai 7 ngay gan nhat
DEST=/backup/etc
NGAY=$(date +%F)                 # 2026-10-19
LOG=/var/log/backup-etc.log

if [ ! -d "$DEST" ]; then
    mkdir -p "$DEST"
fi

if tar -czf "$DEST/etc-$NGAY.tar.gz" /etc 2>/dev/null; then
    echo "$(date '+%F %T') OK  etc-$NGAY.tar.gz" >> "$LOG"
else
    echo "$(date '+%F %T') LOI khi nen /etc" >> "$LOG"
    exit 1
fi

find "$DEST" -name "etc-*.tar.gz" -mtime +7 -delete
  • Dòng 1 shebang: #!/bin/bash (ghi chú gốc viết thiếu /: #!bin/bash)
  • Biến: TEN=gia_tri (không dấu cách), dùng "$TEN"
  • $(lệnh): lấy kết quả lệnh
  • [ -d dir ] thư mục tồn tại · -f file · ! phủ định
  • $? mã thoát lệnh trước: 0 = thành công
  • a && b: a thành công mới chạy b · a || b: a lỗi mới chạy b
# chmod +x /root/backup-etc.sh
# /root/backup-etc.sh ; echo $?
0
# tail -1 /var/log/backup-etc.log

Lab A · 40 phút

Bảo vệ SSH trên server1

  1. Trên server1 tạo /etc/ssh/sshd_config.d/00-lab.conf: cổng 2222, AllowUsers root nhanle
  2. Gán nhãn SELinux cho cổng 2222, mở firewall, sshd -t, restart (giữ 1 phiên cũ đang mở!)
  3. Từ máy Windows: ssh -p 2222 nhanle@192.168.229.29 → OK; user test → bị từ chối
  4. Trên server2: ssh-keygen cho root, ssh-copy-id sang root@server1:2222, đăng nhập không mật khẩu
  5. Từ Windows: tạo khóa, chép khóa công khai lên tài khoản nhanle của server1
  6. Đặt PermitRootLogin prohibit-password → root chỉ vào được bằng khóa. Kiểm tra bằng sshd -T
  7. Dùng scp chép /etc/hosts từ server1 về Windows
Nhắc lại bẫy thứ tự Include: nếu cài đặt Rocky có tick "Allow root SSH login with password" thì có file 01-permitrootlogin.conf. Đặt file 00-lab.conf sẽ được đọc trước nên thắng.

Lab B · 50 phút · theo ghi chú “Lab RSYNC CRONTAB”

Sao lưu /home của server1 về server2 mỗi 5 phút

  1. server2: đảm bảo root SSH vào server1 bằng khóa (Lab A bước 4)
  2. server2: chạy tay lệnh rsync kéo /home/ của server1 về /backup/server1-home/ – không được hỏi mật khẩu
  3. Viết /root/rsync-home.sh chứa lệnh đó, ghi log có ngày giờ vào /var/log/rsync-home.log
  4. chmod +x, chạy thử, xem log
  5. Tạo /etc/cron.d/rsync-home chạy script mỗi 5 phút
  6. server1: tạo file mới trong /home/nhanle, xóa một file cũ → chờ ≤ 5 phút → kiểm tra server2
  7. Xem /var/log/cron trên server2 để thấy cron đã chạy
Lời giải tham khảo 
#!/bin/bash
SRC=root@192.168.229.29:/home/
DEST=/backup/server1-home/
LOG=/var/log/rsync-home.log
mkdir -p "$DEST"
echo "== $(date '+%F %T') bat dau" >> "$LOG"
/usr/bin/rsync -az --delete -e "ssh -p 2222" \
    "$SRC" "$DEST" >> "$LOG" 2>&1
echo "== $(date '+%F %T') ket thuc, ma $?" >> "$LOG"
*/5 * * * * root /root/rsync-home.sh

Lab C · 20 phút

Sao lưu cấu hình hằng đêm

  1. Trên server1, gõ lại script /root/backup-etc.sh (slide “Script bash”)
  2. Chạy tay, kiểm tra có file /backup/etc/etc-<ngày>.tar.gz và dòng log
  3. Lên lịch chạy 1:30 sáng mỗi ngày bằng crontab -e của root
