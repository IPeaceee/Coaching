Lý thuyết

Linux là gì?

Linux thực chất là kernel (nhân) – phần mềm điều khiển phần cứng, do Linus Torvalds viết năm 1991.

Một hệ điều hành Linux = kernel + công cụ GNU (bash, ls, cp…) + trình quản lý gói + ứng dụng. Gói tất cả lại gọi là một distro (bản phân phối).

Ở đâu cũng có LinuxMáy chủ web, cloud (AWS, Azure), Android, router, TV, siêu máy tính.

Lý thuyết

Ổ đĩa & phân vùng được đặt tên thế nào?

TênÝ nghĩa
/dev/sdaỔ SATA/SCSI thứ nhất
/dev/sdbỔ thứ hai
/dev/sda1Phân vùng 1 của ổ sda
/dev/nvme0n1p2Ổ NVMe 0, phân vùng 2
/dev/vdaỔ ảo (KVM/cloud)
/dev/sr0Ổ CD/DVD

MBR (cũ)

Tối đa 4 primary, hoặc 3 primary + 1 extended (chứa nhiều logical). Ổ ≤ 2 TB.

GPT (mới, đi với UEFI)

Tới 128 phân vùng, ổ rất lớn. Mặc định trên máy hiện đại.

Tối thiểu để cài Linux/ + swap. Máy UEFI cần thêm /boot/efi.

Ví dụ

Phương án 1 — Phân vùng cơ bản (2 ổ đĩa)

/boot1 GB · sda1
swap2 GB · sda2
/phần còn lại · sda3
/hometoàn bộ ổ sdb · sdb1

Ổ sda (20 GB) chứa hệ thống, ổ sdb (10 GB) chứa dữ liệu người dùng.

Vì sao tách /home?Cài lại hệ điều hành mà không mất dữ liệu user; user đầy đĩa không làm “treo” hệ thống. Cùng lý do, máy chủ mail/log/CSDL nên tách /var.
Ghi chú gốc: “swap = 2 × RAM”Quy tắc cũ. Ngày nay: RAM ≤ 2 GB → 2×RAM; 2–8 GB → bằng RAM; > 8 GB → 4–8 GB (cần ngủ đông thì ≥ RAM).

Ví dụ

Phương án 2 — LVM: gộp nhiều ổ thành một “bể”

Ổ vật lý/dev/sda3, /dev/sdb
→
Physical Volume (PV)pvcreate
→
Volume Group (VG)vgcreate — “bể” dung lượng
→
Logical Volume (LV)lvcreate → mount vào / , /home
  • Vẫn cần /boot là phân vùng thường (ngoài LVM)
  • LV có thể mở rộng khi đang chạy – thêm ổ mới vào VG là xong
  • Rocky & Ubuntu Server cài mặc định đã dùng LVM
# lvs
  LV   VG   Attr       LSize
  root rl   -wi-ao---- 17.0g
  swap rl   -wi-ao----  2.0g
RAID (biết khái niệm)RAID 1 = 2 ổ soi gương nhau (chịu hỏng 1 ổ). RAID 5 = ≥ 3 ổ, có parity. RAID cứng do card RAID làm, RAID mềm do Linux (mdadm) làm.

Demo

Các bước cài Rocky Linux 9

  1. Tạo VM, gắn file ISO Rocky-9-latest-x86_64-minimal.iso, thêm ổ thứ hai 10 GB
  2. Boot → chọn Install Rocky Linux 9 → ngôn ngữ English (khuyên dùng để dễ tra lỗi)
  3. Installation Destination → chọn cả 2 ổ → Custom → Standard Partition → tạo phân vùng như phương án 1
  4. Network & Host Name → bật card mạng (ON) → hostname server1.lab.local
  5. Root Password → đặt mật khẩu, tick Allow root SSH login with password (chỉ cho lab)
  6. User Creation → tạo user của bạn, tick Make this user administrator
  7. Begin Installation → chờ xong → Reboot System → tháo ISO
Chiếu màn hình cài trực tiếp. Nhấn mạnh bước Custom partition: thêm /boot 1GiB, swap 2GiB, / phần còn lại trên sda; /home toàn bộ sdb. Nếu máy học viên yếu, cho 1.5GB RAM vẫn chạy được bản minimal.

Lab 1 · 60 phút

Cài Rocky Linux 9 với phân vùng tự chọn

  1. Tạo VM theo cấu hình ở slide “Môi trường thực hành” (2 ổ: 20 GB + 10 GB)
  2. Phân vùng: /boot 1 GiB, swap 2 GiB, / phần còn lại trên sda; /home toàn bộ sdb
  3. Đặt hostname server1.lab.local, bật mạng, tạo root + một user thường có quyền admin
  4. Sau khi cài, đăng nhập bằng root và chạy: lsblk, df -h, free -h, ip a
  5. Đăng xuất (exit), đăng nhập bằng user thường – để ý dấu nhắc $ thay vì #
  6. Tắt máy bằng poweroff → chụp snapshot tên 01-fresh-install
Kết quả cần đạtẢnh chụp lệnh lsblk giống slide “Đăng nhập lần đầu”.

Bài tập

Kiểm tra nhanh

  1. File cấu hình hệ thống thường nằm trong thư mục nào?
    Đáp án/etc
  2. Ổ SATA thứ hai, phân vùng thứ ba có tên thiết bị là gì?
    Đáp án/dev/sdb3
  3. Ổ MBR, bạn cần 6 phân vùng. Làm thế nào?
    Đáp án3 primary + 1 extended; trong extended tạo các logical (sda5, sda6, sda7…). Hoặc dùng GPT.
  4. Nêu 2 lợi ích khi đặt /home trên phân vùng riêng.
    Đáp ánCài lại OS không mất dữ liệu user; user ghi đầy đĩa không làm đầy phân vùng /.
  5. Thành phần nào của LVM được mount vào thư mục: PV, VG hay LV?
    Đáp ánLV (Logical Volume), sau khi đã định dạng filesystem.
  6. Swap tương đương thứ gì trên Windows?
    Đáp ánpagefile.sys – bộ nhớ ảo trên đĩa.

Trắc nghiệm nhanh · 5 phút

Kiểm tra trước khi về

  1. Phân vùng nào bắt buộc khi cài Linux: /, /boot, /home hay swap?
    Đáp ánChỉ /. Swap rất nên có; /boot cần tách khi dùng LVM/mã hóa.
  2. Máy UEFI cần thêm phân vùng gì?
    Đáp ánEFI System Partition (ESP) – FAT, mount ở /boot/efi.
  3. Trong LVM, đối tượng nào được mkfs và mount?
    Đáp ánLogical Volume (LV).
